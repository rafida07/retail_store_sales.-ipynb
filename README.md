# Retail Store Sales Analysis

## Project Overview

This project focuses on cleaning, preprocessing, and analyzing a Retail Store Sales dataset using Python and Excel.

Project Objectives

* Understand the raw retail store sales dataset.
* Identify missing values and duplicates.
* Handle missing values.
* Detect and handle outliers.
* Clean and transform the data.
* Perform data analysis and generate insights.

## Tools Used

* Python
* Pandas
* Jupyter Notebook
* Microsoft Excel
* GitHub

## Dataset Information

The dataset contains retail store sales information, including customer details, product categories, quantities, discounts, and total spending.
